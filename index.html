04有用功、额外功与总功

W总 = W有用 + W额外
W额外 = W总 − W有用
W总
动力对机械所做的全部功J
W有用
为完成目标需要做的功J
W额外
除有用功之外的功，如提升动滑轮、克服摩擦等J

三种功必须对应同一次工作过程。有用功由任务决定；本卷滑轮提升任务不把提升动滑轮的功算作有用功。

W总

分子、分母须是同一过程的功，单位一致。实际机械有额外功，效率小于100%；完全理想的模型可为100%。

06杠杆平衡条件

F1l1 = F2l2
F1 = F2l2l1
F₁
动力N
l₁
动力臂：支点到动力作用线的垂直距离m；也可统一用cm或相同格数
F₂

杠杆处于平衡状态，动力与阻力产生相反的转动效果。力臂是垂直距离，不一定等于杆长。下标1、2只用来区分动力和阻力。

m砣

F = Gn （进一步忽略动滑轮重）
F

η = GhFs × 100%
η = GnF × 100%
η = GG + G动 × 100% （忽略绳重与摩擦）

滑轮组的机械效率无单位，通常用百分数

11斜面提升的机械效率

η = GhFL × 100%
W额外 = FL − Gh
η

G
沿斜面被提升物体的重力N

第5、8、17、18题

12机械能的组成

E机 = E动 + E势
E机
物体的机械能J
E动
物体因运动而具有的动能J
E势
物体的势能；包括题中涉及的重力势能或弹性势能J
使用条件

本卷以定性判断为主：质量一定，速度越大动能越大；高度越高重力势能越大；弹性形变越大，弹性势能通常越大。不能仅凭“动能变大”判断机械能一定变大，还要看势能。

背诵句机械能是动能与势能的总和。

13吸热与放热：比热容公式

Q吸 = cmΔT = cm(T末 − T初)
Q放 = cmΔT = cm(T初 − T末)
Q吸
物体升温时吸收的热量J
Q放
物体降温时放出的热量；本卡不是燃料燃烧公式J
c
物质的比热容J/(kg·℃)
m
吸热或放热物体的质量kg
ΔT
温度变化量的大小；吸热升温取末温减初温，放热降温取初温减末温℃
T初
物体变化前的初始温度℃
T末
物体变化后的最终温度℃
使用条件

物质状态不变、比热容可视为不变的升温或降温过程。Δ读作“德尔塔”，表示变化量。课本也常用t、t₀表示温度；本页用T，避免与时间t混淆。

背诵句热量等于比热容乘质量乘温差。

14比热容公式的变形

c = QmΔT
ΔT = Qcm
m = QcΔT
Q
该升温或降温过程中吸收或放出的热量大小J
c
物质的比热容J/(kg·℃)
m
吸热或放热物体的质量kg
ΔT
温度变化量的大小℃
使用条件

三式都是Q = cmΔT的变形，适用条件相同。加热图像中，同m、同Q时，ΔT越小，c越大；同m、同ΔT时，Q越大，c越大。

背诵句求谁就把谁单独放一边；比热容大，同样吸热升温慢。

15升温后的温度与沸点检查

T末 = T初 + ΔT
ΔT实际 = 100℃ − T初 （水已升到沸点时）
T末
加热后水的最终温度℃
T初
加热前水的初始温度℃
ΔT
由Q/(cm)计算出的升温量，须先检查是否达到沸点℃
ΔT实际
实际升温量；本卷水达到100℃后不再继续升温℃
使用条件

第二式专用于本卷：标准大气压、普通敞口加热，初温低于100℃且水已升至100℃，仍有液态水存在。若热量不足以到沸点，仍用Q/(cm)。汽化吸热不能直接当成继续升温。

背诵句先算温升，再查末温；达到沸点，继续吸热不升温。

Q放 = mq
m = Q放q
q = Q放m
Q放
燃料完全燃烧释放的热量J
m
完全燃烧的燃料质量，不是被加热液体的质量kg

21效率之差与相对提高率

Δη = η新 − η原
r = η新 − η原η原 × 100%
η新
改进后的效率；本卷对应氢能源汽车无单位，常用百分数

04这些符号和单位最容易混

同一个字母在不同公式里可能有不同含义。

W：功，还是瓦特？

在P = W/t中，W是“功”的符号，单位是J；在P = 400 W中，W是功率单位“瓦特”。看它出现在公式里，还是跟在数值后面。

t与T：时间与温度

本页t表示时间，单位s；T表示温度，单位℃。课本Q = cm(t − t₀)里的t、t₀表示温度，不能当成时间。

m与m：质量与米

公式G = mg中的m是质量，单位kg；数值“10 m”后的m是长度单位米。

s：距离与秒

W = Fs中的s是距离，单位m；“30 s”中的s是时间单位秒。不要把字母符号与单位混为一谈。

m、Q：看属于谁

Q = cmΔT中的m是吸热或放热物体的质量；Q = mq中的m是燃料质量。两者通常不是同一个质量。Q吸和Q放的下标说明热量是吸收还是放出。

η与P：占比与快慢

η表示效率，看有用部分占总量多少；P表示功率，看单位时间做功多少。效率没有单位，功率单位是W。

n：绳段数与转速

s = nh中的n是承重绳段数；本页n转是飞轮转速，单位r/min。定义不同，不能串用。

下标与Δ

“有用、总、额外、初、末、绳、物、动”等下标用于标明对象或状态；数字1、2用于区分两个量。Δ表示“变化量”，不是另一个要相乘的字母。

百分数怎么代入？

50% = 0.50。W有用 = ηQ放中把η代为0.50，不能代成50。效率公式中的“×100%”是百分数表达；不要再多乘一次100。

1 kg = 1000 g300 g = 0.3 kg；2 kg = 2000 g

1 min = 60 s算功率前，分钟要换成秒

1 W = 1 J/s1 kW = 1000 W；1 kJ = 1000 J

1 m = 100 cm算功时用m；杠杆两边可统一用cm

1 L = 10⁻³ m³体积型热值用J/m³，体积就配m³

ΔT = T末 − T初用于升温；“升高到”不等于“升高了”

一张卡的背诵方法：先读公式和背诵句 → 不看解释说出全部字母及单位 → 说出适用条件 → 开启自测，逐张检查。优先背熟：W = Fs、P = W/t、杠杆平衡、机械效率、Q = cmΔT、Q = mq。

02四个优先提高方向

证据、解释、练法与掌握标志放在一起。

01

先把物理关系画清楚

杠杆、滑轮组与有用功的对象对应，是优先补强的部分。

作答证据
第13题三空错误；第16题动力臂需核查；第20题拉力、支点和称量判断错误；第22题把600 N拉力与物体上升10 m相乘。
诊断解释
能做第15题的简单功计算，但换到滑轮组情境后没有保持“力—距离—对象”的对应。说明需要练情境建模，而非只背公式。
提高方法
每题先标“目标物体”和“动力作用点”；杠杆找支点、画作用线、作垂线；滑轮数承重绳段，再分别写物体高度与绳端路程。
掌握标志
能解释为何有用功用Gh、总功用Fs；换一张滑轮或杠杆图，也能独立完成对应。
02

把相近概念的边界分开

热值与比热容、吸热能力与升温快慢、平衡与水平，存在混淆。

作答证据
第1题把节省燃料归于比热容；第19题选b吸热能力更强；第20题把静止倾斜判为不平衡。
诊断解释
容易从题目表面特征直接选结论，尚未稳定抓住定义中的比较条件。第19题K“小于”答对，但与吸热能力判断不一致，需通过讲解确认理解。
提高方法
用成对比较背概念：热值看燃料单位质量/体积放热，比热容看单位质量升温所需热量；同质量、同吸热，升温慢的比热容大；静止可平衡，水平是便于读力臂。
掌握标志
面对“什么相同、什么改变”的追问，能先说比较条件，再给结论，不只报选项。
03

列式后补上单位与数量级检查

公式写对后，仍要检查代入、计算及物理条件。

作答证据
第21题写出正确公式与0.3 kg，却算出0.8℃；第23题把2000 g与J/kg直接相乘；第14题吸热量对、燃气用量错。
诊断解释
错误出现在不同环节：第21题有算术及沸点检查问题，第23题是量与单位未配套，第14题后续连接或运算需复盘。不能统一归为“不会换算”或“粗心”。
提高方法
固定五行：已知量与单位 → 物理关系 → 代入带单位 → 科学计数法分步运算 → 检查数量级和限制条件。
掌握标志
能说清为什么J/kg要配kg；算完温升会回查末温，算完效率会检查是否在合理范围。
04

让实验操作与研究结论连起来

已能认出观察指标，但研究变量、控制条件和结论的对应还需加强。

作答证据
第18题正确写“木块移动距离、钢球”，却把研究变量写为高度；第19题把多余控制量选A，且吸热能力判断相反。
诊断解释
能说实验怎么做，但有时把操作条件当作研究变量，或没有把表格数据转化为比较条件。
提高方法
每题只写四句话：研究谁的什么量；改变什么、控制什么；观察什么；由现象推出什么。先圈研究目的，再看图表。
掌握标志
能说明改变钢球释放高度是为了改变碰撞前速度；能说明同加热时间、同质量时，温升小对应比热容大。

03逐题错误索引

点击题目，查看实际作答和针对性建议。

只列需要订正或进一步核查的题目。

第1题热值与比热容混淆概念辨析

实际作答卡上选A；应选B。

订正依据做相同工作，燃料消耗较少，比较的是单位质量燃料能释放多少热量，即热值。

下一步怎么练练习前先判断对象是“燃料供能”还是“物质升温”；分别用q与c解释。

第5题机械能变化判断错误过程分析

实际作答卡上选C；应选D。

订正依据加速上升时，动能因速度增大而增大，重力势能因高度增加而增大，所以机械能增大。

下一步怎么练把“速度变化—动能变化”和“高度变化—重力势能变化”分别写出，再合并判断。

第10题吸热图像与比热容对应不稳图像推理

实际作答卡上选BC；正确为AC。

订正依据同样加热时间对应相同吸热量；升温较慢的乙是水。甲、乙比热容之比为1∶2，升高相同温度的吸热量之比也为1∶2。

下一步怎么练读图先列三项：质量是否相同、加热条件是否相同、比较的是温度还是温升。

第12题四冲程关系与转速转换出错关系转换

实际作答卡上转速写300 r/min；应为2400 r/min，另外两空正确。

订正依据单缸四冲程每做功一次飞轮转2圈；每秒做功20次，对应每秒40圈，再乘60换成每分钟。

下一步怎么练按“做功次数 → 飞轮圈数 → 每分钟转速”画箭头。仅凭最终答案，无法确定具体错在其中哪一步。

第13题费力杠杆及力臂变化判断错误图示建模

实际作答卡上写“等臂；变大；变大”；应为“费力；变小；变小”。

订正依据握笔位置下移时，题目模型中的阻力臂变小，所需动力减小；不能只凭笔杆外形判断杠杆类型。

下一步怎么练在示意图中标支点、动力与阻力作用线，画出两条力臂后再比较。

第14题第一步正确，后续燃料用量错误多步连接

实际作答吸热量3.4×10⁴ J及“剧烈”正确；天然气用量应为8.5×10⁻⁴ m³。

订正依据先算Q吸 = cmΔT；题设全部供热时令Q放 = Q吸，再由V = Q放/q求体积。

下一步怎么练把前一步正确的Q保留作中间量，检查除以热值时指数与单位。照片未提供足够清晰的完整计算链，具体原因需复盘。

第16题动力臂作图需核查作图规范

实际作答按照片可辨部分，支点和绕线可识读；动力臂未见规范的支点至动力作用线的垂线。

订正依据动力臂是支点到动力作用线的垂直距离，不是力作用点附近任意一段线，也不一定等于杆长。

下一步怎么练固定顺序：支点 → 延长力的作用线 → 作垂线 → 标垂足与力臂符号；原图不清处由原卡再确认。

第17题机械效率结果错误，具体环节待定位模型与计算

实际作答卡上1、匀速、2.4 N正确，效率写50%；正确为75%。

订正依据本图n = 3，η = G/(nF) = 5.4/(3×2.4) = 75%。读数与操作要求已答对。

下一步怎么练让学生口述数绳过程，再列有用功和总功。只有最终50%的答案，不能直接认定就是数绳错误。

第18题操作高度与研究速度混淆实验变量

实际作答前两空“木块移动距离、钢球”正确；后两空应为“速度、速度越大”。

订正依据释放高度不同，改变的是钢球到水平面时的速度；研究的是钢球动能与速度的关系。

下一步怎么练写出因果链：释放高度不同 → 碰撞前速度不同 → 推动距离不同 → 动能不同。结论写研究变量。

第19题比较条件与吸热能力判断错误实验推理

实际作答装置、前面比较及“转换”“小于”正确；多余控制量应选B，吸热能力更强的应选a。

订正依据相同质量、同样加热6 min：a温升6℃、b温升12℃。a升温慢，cₐ较大；K = 1/c，故Kₐ较小。多余控制量是燃料总质量B，而非加热方式A。

下一步怎么练用“相同m、相同Q → ΔT小 → c大 → K小”连续解释。K关系答对不能单独证明该概念已稳定掌握。

第20题平衡、力臂与杆秤模型衔接不足图示建模

实际作答卡上“左”“变小”正确；其余对应应为“平衡、力臂、2 N、秤纽、5 kg”。

订正依据静止倾斜仍可平衡。图乙OA为4格、OB为3格，F = 1.5×4/3 = 2 N。杆秤支点在秤纽，最大称量m = 0.2×0.5/0.02 = 5 kg。

下一步怎么练区分“物体状态”和“实验调节目的”；先找支点、读力臂，再列平衡关系，不直接把秤砣质量当最大称量。

第21题公式与质量换算正确，运算及沸点漏查运算与复核

实际作答比热容一空正确；300 g = 0.3 kg和ΔT = Q/(cm)正确，但最后写0.8℃。

订正依据按代入应得理论温升80℃。水初温25℃，标准大气压下到100℃沸腾，实际温升为75℃。

下一步怎么练这里有两道检查：先核算科学计数法，再用“初温+温升”检查末温是否超过沸点。不能把本题诊断成不会换算kg。

第22题力与距离错配，并影响后续计算对象对应

实际作答卡上有用功写6000 J、功率写200 J/s；机械效率一问留空。

订正依据有用功为960 N×10 m = 9600 J。n = 2，绳端移动20 m，总功为600 N×20 m = 12000 J；功率400 W，效率80%。200 J/s的单位本身合法，主要问题在功的代入。

下一步怎么练列成两行：物体端“960 N、10 m”；绳子端“600 N、20 m”。算完两个功再分别求功率和效率。

第23题换算后单位不配套，综合末问未完成单位与连接

实际作答“热值不变”正确；写2000 g乘J/kg形式的热值，得到2.8×10¹¹ J；末问留空。

订正依据2 kg = 2000 g换算本身对，但应使用2 kg×1.4×10⁸ J/kg = 2.8×10⁸ J。同阻力、同路程，两车有用功相同，再求汽油机效率约30.4%。

下一步怎么练保留kg与J/kg配对；把“燃料放热 → 有用功 → 相同有用功 → 另一辆车效率”写成链条。末问“提高”口径有歧义：效率差约20个百分点，相对提高约64%，不能把歧义本身算作学生错误。

04具体怎么提高

先练关系，再练运算，最后连成完整解题过程。

第一阶段 · 图示建模

先画，再列式

每题必须标出支点与力的作用线，或分别列“物体端、绳子端”的力与距离。换图后仍能解释，而不是记住原题数值。

对应重做：13、16、17、20、22题
第二阶段 · 运算复核

单位带进代入式

热值J/kg配kg，吸热公式用液体质量，燃烧公式用燃料质量。科学计数法把系数与指数分开算；温升计算后检查末温。

对应重做：14、21、23题
第三阶段 · 实验迁移

用条件解释结论

改图或换数据后，先说研究对象、改变因素、控制量和观察指标，再得结论。把第22、23题末问补写成完整链条。

对应重做：18、19题及综合题末问
一次约25分钟的练习循环
5分钟讲概念 → 10分钟做同类题 → 5分钟口述错因 → 5分钟独立复核

订正不能只抄正确答案：盖住原过程，重做后解释“原来哪一步错、为什么、下次先检查什么”。隔一天换数或换图再做。

两处未作答，单独复盘

第22(3)、23(3)题的空白，只能说明本次没有写出答案。先问学生“卡在读题、关系、运算，还是时间”，再安排对应练习，不能据此认定学习态度或能力。

若已算出前面中间量：先把下一步公式写出来。第22题连接η = W有用/W总；第23题连接“相同阻力与路程 → 两车有用功相同 → 汽油机效率”。

05用四道小题验证是否理解

独立说理由，比记住原题答案更有用。

① 杠杆：先看力臂

杠杆左侧3 N，力臂4格；右侧力臂3格。平衡时右侧力多大？静止但倾斜的杠杆能否处于平衡？

查看推理

3×4 = F×3，所以F = 4 N。静止倾斜的杠杆可以平衡；水平与否不是判断平衡的唯一依据。需能解释力臂是垂直距离。

② 滑轮：力和距离配对

物重400 N，拉力250 N，承重绳2段。匀速提升2 m，用时5 s。有用功、总功和功率各是多少？

查看推理

W有用 = 400×2 = 800 J。绳端路程s = 2×2 = 4 m，W总 = 250×4 = 1000 J。拉力功率P = 1000/5 = 200 W。不能用250×2代替总功。

③ 单位：换算不能脱离热值

3 kg燃料完全燃烧，热值2×10⁷ J/kg。放热多少？若改用3000 g，热值的单位和数值应怎样配套？

查看推理

Q = 3 kg×2×10⁷ J/kg = 6×10⁷ J。若用3000 g，则热值要换为2×10⁴ J/g。直接用kg更简便。

④ 实验：升温慢说明什么

同质量的a、b两液体，用相同装置加热相同时间，a升5℃、b升10℃。谁的比热容更大？能否说b吸热更多？

查看推理

按题设加热模型，吸热量相同；cₐ/cᵦ = 10/5 = 2，a的比热容更大。b升温更快，不能据此说它吸热更多。需先说“同质量、同吸热”。

后续观察：如果能独立解释这些同类题，再回到原卷重做，才能判断知识是否真正连起来。若只能复述原答案，应继续练换图、换条件的题目。
